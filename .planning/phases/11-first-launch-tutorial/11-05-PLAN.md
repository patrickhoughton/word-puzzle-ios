<objective>
Wire the tutorial into the running app. WordPuzzleApp owns the `TutorialController` and decides at launch (after the word list loads) whether to show it. ContentView swaps the root to a tutorial GameView with the practice view-model injected. GameView routes every input through the controller when in tutorial mode, and shows the banner, highlights, dimming, Skip link and Settings replay.

Decisions this plan implements: D-01/D-02 (strict guided input), D-03 (no missed-words cover, free play), D-07 (no recording, no paywall), D-08/D-09 (launch gate, premium included), D-10 (Finish hand-off), D-11 (Skip), D-12 (replay resumes the real round), D-13 (no step persistence).

Research open questions resolved: replay ending RESUMES the real round untouched (no free-puzzle cost); the hand-off closure is set by WordPuzzleApp and calls `requestNextRound` only for a first-launch exit while the real VM is still `.loading`.

Purpose: Makes the tutorial real for players.
Output: 3 edited files.
</objective>
