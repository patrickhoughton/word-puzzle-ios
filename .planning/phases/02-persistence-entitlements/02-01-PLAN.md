Two separate wiring steps are required, and they are easy to confuse (RESEARCH Pitfall 5).
Xcode's Target Membership checkboxes and the scheme's StoreKit Configuration dropdown are
independent. Neither has a CLI equivalent, so this is a genuine manual step.

Open `WordPuzzle/WordPuzzle.xcodeproj` in Xcode first.

--- STEP A: Target membership (REQUIRED for SKTestSession to find the file) ---------
1. In the left-hand Project Navigator (folder icon, or Cmd+1), expand the blue
   **WordPuzzle** project -> the yellow **WordPuzzle** folder.
2. Click once on **WordPuzzle.storekit**.
   (If it is not visible, Xcode has not picked up the new file yet — close and reopen
   the project. Because this folder is a synchronized group, no "Add Files" step is needed.)
3. Open the File Inspector on the right: menu **View -> Inspectors -> File**, or press
   **Option+Cmd+1**.
4. Scroll to the **Target Membership** section.
5. Tick BOTH checkboxes:
     [x] WordPuzzle
     [x] WordPuzzleTests
   (WordPuzzle is likely already ticked automatically. WordPuzzleTests is the one that
   matters — without it, `SKTestSession(configurationFileNamed: "WordPuzzle")` throws at
   test runtime in plan 02-04 even though the file exists on disk.)
6. Press **Cmd+S**. Xcode writes a `PBXFileSystemSynchronizedBuildFileExceptionSet`
   entry into project.pbxproj — this is what makes the change greppable and committable.

--- STEP B: Scheme StoreKit Configuration (for manual Simulator runs) ---------------
1. Menu **Product -> Scheme -> Edit Scheme...** (or Cmd+<).
2. Select **Run** in the left column -> **Options** tab.
3. Find the **StoreKit Configuration** dropdown -> select **WordPuzzle.storekit**.
4. Select **Test** in the left column -> **Options** tab.
5. Set its **StoreKit Configuration** dropdown to **WordPuzzle.storekit** as well.
6. Click **Close**.

   IMPORTANT for later: before the real sandbox purchase test in plan 02-05 Task 3, this
   Run dropdown must be switched back to **None**. A local StoreKit configuration
   overrides the real App Store sandbox, so leaving it set would make the "sandbox" test
   silently test the local config instead. Plan 02-05 repeats this instruction.
