  <action>
**Part A — `scripts/capture-screenshot.sh`** (executable, `chmod +x`).

Usage: `bash scripts/capture-screenshot.sh <output-path.png>`.

It must:
1. Assert a Simulator is booted (`xcrun simctl list devices booted` shows a device);
   exit non-zero with a clear message if not.
2. Run `xcrun simctl io booted screenshot --type=png "<output-path>"`.
3. Verify the result with `sips -g pixelWidth -g pixelHeight` and FAIL loudly if
   the dimensions are not 1320x2868, naming the expected size and the device it
   requires (`iPhone 17 Pro Max`). Capturing on the wrong Simulator produces a
   wrong-sized file that App Store Connect will reject at upload — catching it
   here rather than there is the whole point of this check.
4. `mkdir -p` the output directory so the caller does not have to.

**Part B — `scripts/FrameScreenshot.swift`** (standalone macOS Swift script).

Usage: `swift scripts/FrameScreenshot.swift <raw.png> <caption> <out.png>`.

It must:
1. Load the raw 1320x2868 capture with `CGImageSourceCreateWithURL`.
2. Render a 1320x2868 SwiftUI composition containing, top to bottom:
   - A full-bleed background. Use a near-black (`Color(white: 0.08)`) field so
     the gold accent reads strongly; this is the caption backdrop, not part of
     the device screen.
   - The caption text at the top: the `<caption>` argument, `.multilineTextAlignment(.center)`,
     bold, roughly 84pt, `.foregroundStyle` the exact accent gold
     `Color(red: 0xF5/255, green: 0xB8/255, blue: 0x00/255)`, with generous
     horizontal padding (about 100pt) and `.minimumScaleFactor(0.6)` so a longer
     tagline never truncates.
   - Below the caption, the raw screenshot scaled to about 78% width, centred,
     inside a simple device frame: a `RoundedRectangle(cornerRadius: 72)` clip on
     the image plus a matching `RoundedRectangle` stroke of about 10pt in
     `Color(white: 0.25)` as the bezel. This is a deliberate stand-in for real
     device bezel art — `frameit` is unavailable and hand-drawing accurate bezel
     artwork is out of scope for a 3-screenshot v1 set.
   - Bottom padding so the framed device is not flush with the canvas edge.
3. Wrap the render in an `@MainActor func` invoked through
   `MainActor.assumeIsolated { ... }` (`ImageRenderer.cgImage` is MainActor-isolated).
4. Set `renderer.scale = 1` and render a `.frame(width: 1320, height: 2868)` root.
5. Write the PNG via `CGImageDestinationCreateWithURL`. Alpha does NOT need
   stripping here — the alpha-free rule applies to app icons, not screenshots —
   but the background must be fully opaque so no transparency shows through.
6. Exit non-zero with a clear message on bad arguments, a missing input file, a
   nil `cgImage`, or a nil destination.

Verify the compositor before any real captures exist by feeding it a throwaway
capture (boot the iPhone 17 Pro Max Simulator, capture the Home screen, run the
compositor on it with a test caption) and confirming the output is exactly
1320x2868. Delete the throwaway files afterwards — do not commit them.
  </action>
