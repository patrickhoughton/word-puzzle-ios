<interfaces>
Screens that must be visually checked (this is every screen the app has):
- `GameView` playing layout — gear row, ScoreBarView, WordDisplayView,
  LetterGridView hex flower, control row (Shuffle / Delete / Finish Round)
- `SettingsView` — title, Sound Effects toggle, Done button
- `MissedWordsView` — round-end reveal: rank, counts, grouped missed words, pangram badges
- `PaywallView` — countdown, today's stats, price CTA, Restore Purchases
- `GameView` `.loading` state — the "Loading words..." ProgressView

The 05-02 clamp under test: `HexTileView.baseLetterSize = 34`,
`HexTileView.maxLetterSize = 40`, inside a fixed `GameTheme.hexSize = 70`
hexagon. RESEARCH Pitfall 1: an unclamped `@ScaledMetric` scales a 34pt base
past 90pt at AX5, larger than the whole tile. This check confirms the 40pt
ceiling both prevents clipping AND does not look frozen next to the rest of the
now-scaling UI.

Pre-verified environment facts. Do not re-derive:
- `iPhone 17` and `iPhone 17 Pro Max` Simulators are both available.
- Accessibility sizes AX1-AX5 are reached in the Simulator via
  Settings > Accessibility > Display and Text Size > Larger Text, with the
  "Larger Accessibility Sizes" switch turned ON. The standard xxxLarge size is
  NOT sufficient — that is exactly the mistake RESEARCH Pitfall 1 warns about.
- Bundle id: `com.patrickhoughton.WordPuzzle`.

Behaviours that are PASSES, not failures — do not file these as defects:
- RESEARCH Pitfall 2: `Transaction.currentEntitlements` and `AppStore.sync()`
  read a LOCAL cache StoreKit builds by syncing with Apple once. A pristine
  install taken offline before any sync can show an empty entitlement stream
  even for an entitled account. The Airplane Mode test must therefore launch
  once WITH network before going offline.
- RESEARCH Pitfall 3 / D-01: `SoundManager.sessionCategory` is `.ambient`, so
  SFX are silenced by the hardware mute switch by design.
- 05-05 accepted behaviour: on a cold launch by a free user already at the daily
  limit, `.loading -> .paywalled` plays `round_end` with no preceding round.
  D-01 groups "round end / paywall shown" as one event. Judge whether it feels
  acceptable; the default position is that it is intended.

Prior-phase precedent: the physical iPhone used for the Phase 3 on-device
verification (03-05) and the Phase 4 sandbox purchase test (04-04) is the same
device to use here.
