## Spacing Scale

Reuses `GameTheme` tokens; no new values.

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4pt | Gap between "N of M words" text and chevron; gap between group title and checkmark |
| sm | 8pt | Row vertical padding; spacing between rows in LazyVStack; header title/subtitle gap |
| md | 16pt | Row and group-header horizontal padding; group header top padding |
| lg | 24pt | Sheet header padding; scroll content horizontal and bottom padding |
| xl | 32pt | (unused) |
| xxl | 48pt | (unused) |

Exceptions: the whole ScoreBarView tap target already exceeds `minTapTarget` (44pt). "Done" toolbar button uses the system toolbar size. Corner radii match existing: rows 8pt (as MissedWordsView), score bar 12pt (unchanged).

## Typography

Reuse the existing 4 roles (Dynamic Type text styles, 2 weights: regular + semibold). Sizes shown at default Large category.

| Role | Token | Size | Weight | Line Height | Used for |
|------|-------|------|--------|-------------|----------|
| Display | `displayFont` | 34pt (largeTitle) | semibold | system default | NOT used in sheet (sheet title uses Heading) |
| Heading | `headingFont` | 20pt (title3) | semibold | system default | Sheet title "Found Words"; group headers "4 Letters · 3 of 9" |
| Body | `bodyFont` | 17pt | regular | system default | Word text; "+N" points; empty-state nudge |
| Label | `labelFont` | 13pt | regular | system default | Subtitle "<Rank> — N of M words"; "Pangram" badge |

Rules:
- No fixed point sizes. Sheet title is centered Heading (not Display) because the sheet opens at the medium detent and vertical space is scarce.
- "+N" points: `bodyFont`, `Color.secondary`, right-aligned, monospaced digits (`.monospacedDigit()`), `.lineLimit(1).minimumScaleFactor(0.5)`.
- Group header: `.lineLimit(1).minimumScaleFactor(0.5)` (Phase 5 shrink-to-fit pattern); never wraps.
- Word text: `.lineLimit(1).minimumScaleFactor(0.5)`, `.layoutPriority(1)` so the word wins over the badge and points at accessibility sizes. At accessibility Dynamic Type sizes (`dynamicTypeSize.isAccessibilitySize`) the "Pangram" badge shows icon only (`.labelStyle(.iconOnly)`); the combined accessibility label still says ", pangram".

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `GameTheme.dominant` (systemBackground) | Sheet background |
| Secondary (30%) | `GameTheme.secondarySurface` | Word rows (8pt rounded rect); existing ScoreBarView card |
| Accent (10%) | `GameTheme.accent` (honeycomb gold #F5B800) | See reserved list |
| Destructive | n/a | No destructive actions; `errorColor` not used |

Accent reserved for:
1. Pangram word text and its `checkmark.seal.fill` "Pangram" badge (identical to MissedWordsView, D-14)
2. Completed-group checkmark on group header (D-12)
3. "Done" toolbar button (system tint, same as SettingsView)

Not accent: chevron in ScoreBarView (use `Color.secondary`), "+N" points (secondary), nudge line (secondary), zero-found group headers (primary).

## Layout and Interaction Contract

### Entry point (D-01, D-02)
- `ScoreBarView` wrapped in a `Button` in `GameView.playingLayout` with `.buttonStyle(.plain)`; whole bar is the tap target. Available at all times during `.playing`.
- Chevron: `Image(systemName: "chevron.right")`, `labelFont`, `Color.secondary`, placed immediately after the "N of M words" text with `xs` (4pt) spacing, inside the same trailing group so shrink-to-fit still applies. Decorative (`accessibilityHidden(true)`).
- Pressed state: plain style plus slight opacity (0.7) while pressed via a small custom `ButtonStyle`; no layout change.
- ScoreBarView gains no view-model coupling: tap handled by wrapper Button in GameView (closure-out); ScoreBarView stays value-in.
- Accessibility: `.accessibilityAddTraits(.isButton)`, hint "Shows the words you've found". Existing combined label unchanged.

### Sheet (D-03, D-04, D-05)
- `.sheet(isPresented:)` state owned by `GameView` next to the Settings sheet; `.presentationDetents([.medium, .large])`, `.presentationDragIndicator(.visible)`.
- Content wrapped in `NavigationStack` with inline toolbar: "Done" button at `.confirmationAction` (copy SettingsView pattern). Swipe-to-dismiss enabled. Modal: board not interactive.
- Sheet is fully scrollable at both detents; scroll position starts at top.

### Structure (top to bottom)
1. Header (centered, `lg` padding): "Found Words" (`headingFont`) over subtitle "<Rank> — N of M words" (`labelFont`, secondary), `sm` between.
2. Nudge line (only when found count == 0): body font, secondary, centered, `md` vertical padding, above groups.
3. `ScrollView` > `LazyVStack(alignment: .leading, spacing: GameTheme.sm)` (never `List`), horizontal padding `lg`, bottom `lg`.
4. For each length present in `puzzle.validWords`, ascending (D-06, D-11): group header then rows.

### Group header (D-10, D-11, D-12)
- Text format: `"\(length) Letters · \(found) of \(total)"` using the middle dot "·" with spaces. `headingFont`, primary color, `md` top padding and `md` horizontal padding (matches MissedWordsView header).
- Complete group (found == total): append `Image(systemName: "checkmark.circle.fill")` in `GameTheme.accent` after text, `xs` gap. Header text stays primary.
- Zero-found groups: header only, no rows, no placeholder text.
- Accessibility: header trait `.isHeader`; combined label "4 letters, 3 of 9 found" (plus ", complete" when full); checkmark hidden from VoiceOver.

### Word row (D-07, D-08, D-13, D-14)
- Words alphabetical within group.
- HStack(spacing sm): word (`bodyFont`, primary or accent if pangram) · pangram badge if pangram (`Label("Pangram", systemImage: "checkmark.seal.fill")`, `labelFont`, accent) · Spacer · "+N" (`bodyFont`, secondary, monospaced digits).
- Row styling copied verbatim from `MissedWordsView.wordRow`: padding vertical `sm`, horizontal `md`, background `secondarySurface` in `RoundedRectangle(cornerRadius: 8)`.
- Accessibility: `.accessibilityElement(children: .combine)`; label "<word>, <N> points" or "<word>, pangram, <N> points".
- Points via `ScoreCalculator.points(for:isPangram:)`; computed in GameView/view-model, not in the view.
- No pangram count/hint line (D-15).

### Data contract (value-in / closure-out)
`FoundWordsView(groups: [FoundWordGroup], pangrams: Set<String>, rank: RankTier, foundCount: Int, totalCount: Int, onDone: () -> Void)`
- `FoundWordGroup: Identifiable { length: Int; found: [String] (alphabetical, each with points); total: Int; isComplete }` — new struct or view-model computed property `foundWordGroups` (planner's discretion; points may be a `[(word, points)]` of a small `FoundWord` struct). View must not touch `GameViewModel`.
- Must include `#Preview`s: mid-round with pangram, empty (0 found), group complete, accessibility XXL size.

### States
| State | Behavior |
|-------|----------|
| Empty (0 found) | Nudge line + all headers at "0 of N" (D-16) |
| Mid-round | Headers with counts, rows for found words |
| All found | Every header shows accent checkmark |
| Round ends while sheet open | Sheet dismisses automatically when state leaves `.playing` (set the sheet flag false) |
| Found count changes while open | Not possible (modal), no live-update requirement |
